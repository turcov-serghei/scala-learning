- Deferred by the user (to revisit later): value discarding. Explanation given: `Boolean` is not a subtype of `Unit`; when the expected type is `Unit`, the compiler turns any expression `e` into `{ e; () }` (value discarding). With `-Wvalue-discard` Scala 2.13 highlights such places, because discarding a value is often accidental.
